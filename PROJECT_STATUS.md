## Required before calling WhatsApp integration complete

On a networked machine: `npm install`, remove `src/web/shims.d.ts`, rerun `npm test`, `typecheck`, `typecheck:web`,
`build:web`. Then, with a **dedicated test number and disposable group**, test mode ON first:

1. QR pairing works; session survives a worker restart; QR re-pair after deleting the session.
2. Admin-sent link/profanity is skipped; participant metadata ids match `message.author` format (watch for `@lid`).
3. Test mode on: violations logged as simulated, nothing deleted.
4. Test mode off, one throwaway member: link -> message deleted for everyone **and** member removed; profanity same.
5. Bot not admin: failure is recorded honestly, not reported as success.
6. Network drop: automatic reconnect with backoff; auth failure stops retries and shows in the dashboard.

Assumptions from memory of the library that this run must confirm: `chat.participants[].isAdmin` populated; 
`message.delete(true)` revokes for everyone (it returns no receipt, so deletion is not independently confirmed);
`removeParticipants` result shape varies (membership re-read is the authority).

## Known limitations

- Masked words (`f*ck`), spaced-dot obfuscation and glued Arabic slurs are not detected (see ARCHITECTURE.md).
- Removal policy is fixed (delete + remove); the UI states this rather than offering a fake toggle.
- Members list has no total count (next page enabled while pages are full).
